# Nellie's Beauty Parlour

A modern luxury beauty parlour booking website.

## About

Nellie's Beauty Parlour provides premium beauty and wellness services in Abuja, Nigeria.

Services include:

- Spa
- Massages
- Aromatherapy
- Facials
- Make-up
- Haircuts
- Pedicures
- Manicures

Home services are also available.
